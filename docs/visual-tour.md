## Ch01 Alembic 是什么

Alembic 的核心不是一个搜索工具，而是一套把项目代码、规则、Agent 任务和 IDE 事件持续炼成可消费知识的本地知识引擎。

## Ch02 SOUL 原则

SOUL 是 Alembic 的工程宪章：诚实表达能力边界、保持本地优先、把不确定性显式上交给用户或 Agent 审核。

![SOUL 身份宪章结构图](/images/ch02/01-soul-charter.png)

*原则、角色、能力探测和执行门控之间的关系。*

## Ch03 架构全景

Alembic 的架构主干是容器化装配：领域模型保持相对纯净，服务层承接业务编排，外部接口通过 CLI、HTTP、MCP、Dashboard 和 VSCode 进入同一组服务。

![Alembic 七层分层架构图](/images/ch03/01-seven-layer-architecture.png)

## Ch04 安全管线

Alembic 的安全不是单点权限检查，而是角色解析、Constitution、Gateway、PathGuard、WriteZone、Sandbox 和审计共同组成的多级管线。
