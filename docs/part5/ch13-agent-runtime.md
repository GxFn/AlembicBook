## 本章结论

- Runtime 本身不等于某个业务 Agent；Profile 和 Strategy 决定它执行何种任务。
- ToolExecutionPipeline 是 Agent 调用工具的关键安全和观测点。
- ContextWindow、BudgetController、ExitController 让长任务有上下文、成本和终止边界。
- DiagnosticsCollector 与 EventBus 让内部 Agent 行为可追踪。

## 真实实现链路

- `AgentRuntimeBuilder` 根据 profile、capability、policy 和工具上下文创建 runtime。
- `SystemPromptBuilder` 汇合系统提示、profile 和任务输入。
- `ToolExecutionPipeline` 调用 Tool V2 router，并处理结果 envelope。
- `AgentService` 为外部接口提供统一运行入口。

## 门控与边界

- 预算耗尽、退出条件满足或策略要求停止时，Runtime 必须终止。
- 工具调用必须经过 pipeline 和 capability，而不能从 LLM 输出直接执行。
- 诊断和错误应被记录，不能吞掉造成假成功。

## 易漂移点

- 策略新增会影响 ch14 的正交组合。
